# 📊 Portfólio de Projetos em Dados  
*(Buscando valor em Dados de ponta a ponta)*

Bem-vindo ao meu portfólio!  
Aqui compartilho parte da minha jornada como **Cientista de Dados** e **Professor**.  

- 🚀 Iniciei explorando **Business Intelligence**, criando dashboards em **Tableau** e **Power BI**.  
- 🧠 Evoluí para **Machine Learning com Python**, desenvolvendo modelos preditivos em cenários reais.  
- 🤖 Atualmente, foco em **Inteligência Artificial Generativa**, explorando agentes inteligentes, automação e integração de modelos de linguagem.  

> **Observação:** Todos os dados são de fontes **públicas** e os projetos têm caráter **acadêmico e experimental**.
